# ✨ Welcome to Nano-Core

Nano-Core is a full system framework designed to streamline the development and deployment of modern cloud-native applications. It brings together application 
frameworks, infrastructure templates, CI/CD pipelines, secrets management, centralized logging, and other supporting capabilities into a unified approach for 
building, deploying, and operating services.

Built with .NET and designed for Kubernetes on Azure, Nano provides a solid foundation for scalable and resilient microservice-based systems. It reduces the need
to manually assemble and maintain disparate tooling by offering a cohesive, opinionated platform from development through to production. The platform includes 
PowerShell-based automation scripts for provisioning cloud resources, along with Helm-based Kubernetes deployments. Continuous integration and delivery are handled 
through GitHub Actions, enabling automated build, test, and deployment workflows.

Nano-Core is based entirely on popular open-source technologies and is fully MIT licensed, giving you complete access to all source code and the freedom to extend 
it as needed.
